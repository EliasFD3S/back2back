# back2back

Site e-commerce back2back, migré de Next.js vers React, TypeScript et Vite.

## Développement

```sh
npm install
npm run dev
```

## Vérification et production

```sh
npm run lint
npm run build
npm run preview
```

Les composants React sont dans `src/components/b2b`, les ressources publiques dans `public/` et les sources Next.js d'origine restent dans `v0/`.
